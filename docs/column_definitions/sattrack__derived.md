# Column definitions: SatTrack-derived columns

Part of the SatTrack column definitions; see `00_overview.md` for the rules and decisions.

## Batch 8: SatTrack-derived columns (intermediate and marts)

Source: SatTrack-derived. Each row names the model or macro that computes it; the publishers of its inputs are cited in the definition.

There's no external publisher for these. Each definition **cites the model or macro that computes it, and the decision that set the rule** (the field review is `~/.claude/plans/sattrack-field-review.md`; the plan is `~/.claude/plans/sattrack-dbt-migration.md`). Each doc block carries a **"SatTrack-derived"** label. Where a rule combines sources, the precedence is spelled out so the definition can be tested. **Corrected 2026-11-08 against the current SQL**; the load metadata and audit rows (#27–#29) moved to `sattrack__metadata.md` (batch 8b).

**v3 placeholders dropped:** `source_priority` (the constant `'v3_python_extract_sql_transform'`) and `record_quality_score` (always NULL) carry no information. They're replaced by the per-field `*_source` lineage columns.

## Batch 9a: SatTrack-derived columns without a definition (added 2026-11-08)
