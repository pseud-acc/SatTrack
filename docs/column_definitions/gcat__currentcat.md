# Column definitions: GCAT current catalog

Part of the SatTrack column definitions; see `00_overview.md` for the rules and decisions.

## Batch 3: GCAT current catalog (`currentcat.tsv` → `stg__jsr__currentcat`)

Source: GCAT "Current Object Catalog Column Descriptions", https://planet4589.org/space/gcat/web/cat/curcols.html. In GCAT's words, currentcat "gives information on the current status of each object, including the most recent orbital data for those objects still in orbit". It is derived from the main catalogs. 2026-10-24 file: 83,576 rows, 0 duplicate JCATs. **Several columns mean something different here than in satcat** (current owner, most recent orbit, first separation, descent), so they get their own names.

| # | GCAT col | Proposed name | Proposed definition (from source) | SatTrack note |
|---|---|---|---|---|
| 1 | JCAT | `jcat` | GCAT: "an alphanumeric identifier (JCAT...) to uniquely tag space objects": a catalog prefix letter plus a sequence number. From GCAT currentcat `JCAT`. E.g. `S25544`, the ISS Zarya module. | **Detail:** (shared block, batch 1 #1) PK. 0 duplicates in the 2026-10-24 file. |
| 2 | DeepCat | `deepcat_jcat` | The object's ID in GCAT's deep space catalog (D prefix). From GCAT currentcat `DeepCat`, a column GCAT doesn't describe; filled for about 1,200 objects. E.g. `D00001`. | **Detail:** **UNSOURCED.** Not described on curcols.html. The values are deepcat JCATs (`D00009`…), and the JCAT page defines the D prefix as the deep space catalog. **Staging only** (undocumented by GCAT). Filled on 1,210 of 83,576 rows. |
| 3 | Satcat | `satcat_ref` | GCAT: "For objects in the US Satcat, this field contains an integer value which is the US SATCAT number"; others hold a reason code. From GCAT currentcat `Satcat`. E.g. `25544` (ISS Zarya); `NNA`. | **Detail:** (shared block, batch 1 #2) |
| 4 | Piece | `cospar_id` | GCAT: "The piece designation for the object. For objects in the US SATCAT this is the COSPAR (International) designation." From GCAT currentcat `Piece`. E.g. `1998-067A` (ISS Zarya). | **Detail:** (shared block, batch 1 #4) |
| 5 | Active | `activity_type` *(existing)* | GCAT: "a single byte giving the type of object": A active satellite, P inactive payload, R rocket stage, C component, D debris. From GCAT currentcat `Ac`. E.g. `P` (ISS Zarya); `A` is the most common. | **Detail:** Single-letter object type: A active satellite, C component, D debris, P inactive payload, R rocket stage, Z spurious entry. Except for A, usually the same as the first letter of Type. (The source page labels this column `Ac`.) Data: D 29,190; A 16,955; C 14,975; P 14,145; R 8,303; Z 8. **The current test accepts `S`, which GCAT doesn't define and which never occurs.** Accepted values become A, C, D, P, R, Z. |
| 6 | Type | `sat_type` | GCAT: "At the coarsest level, we characterize the object as payload (P), rocket stage (R), component (C) or debris (D)." From GCAT currentcat `Type`. E.g. `PPTH-MU` (ISS Zarya). | **Detail:** (shared block, batch 1 #5) |
| 7 | Name | `gcat_name` | GCAT: "My recommended name for the object. The name is based on that used by the owner/operator." From GCAT currentcat `Name`. E.g. `Zarya`; `deb FY-1C` (Fengyun-1C debris). | **Detail:** (shared block, batch 1 #6) |
| 8 | LDate | `gcat_launch_date` | GCAT: "The launch date is given in UTC, with 1 day precision." From GCAT currentcat `LDate` (a Vague Date). E.g. 1998-11-20 for the ISS Zarya module. | **Detail:** (shared block, batch 1 #8) |
| 9 | Parent | `parent_ref` | GCAT: "the 'parent object' which the object is attached to at the start of the phase, or the central body whose gravitational sphere the object is leaving." From GCAT currentcat `Parent`. E.g. `S25545`. | **Detail:** (shared block, batch 1 #9) |
| 10 | Owner | `current_owner_code` | GCAT: "the organization which currently owns the object if it is still in space, otherwise the organization which owned the object at the time of reentry." From GCAT currentcat `Owner`. E.g. `JSC` (ISS Zarya). | **Detail:** OrgCode of the organisation that **currently** owns the object if it's still in space, otherwise the owner at re-entry. In the primary catalogs, by contrast, the owner is the one at the start of the listed phase. Not the same as satcat `owner_code`, hence the new name. |
| 11 | State | `current_state_code` | GCAT: "The country (or equivalent) associated with the owner." From GCAT currentcat `State`. E.g. `US` for the ISS Zarya module; `SU`, `CN`. | **Detail:** Country (or equivalent) associated with the current owner. |
| 12 | SDate | `first_separation_date` | GCAT: "the time when the object first separated from its parent", useful "for determining when debris objects appeared in orbit." From GCAT currentcat `SDate`. Not carried into SatTrack's models. | **Detail:** UTC time when the object **first** separated from its parent, in Vague Date format. Later phases (dockings, undockings) aren't given here. Useful for telling when debris appeared in orbit. Not the same as satcat `phase_start_date`. |
| 13 | ExpandedStatus | `current_status` *(existing)* | GCAT: "the current status of the object... derived from the Status and Dest fields for the most recent phase." From GCAT currentcat `ExpandedStatus`. E.g. `In Earth orbit` (ISS Zarya); `Reentered Earth atmosphere`. | **Detail:** Current status of the object, derived from the Status and Dest fields of its most recent phase in the object catalogs. Meant to be self-explanatory, e.g. "In Earth orbit", "Reentered Earth atmosphere", "Attached to A08069 ISS Generic Cargo". Free text, so no accepted-values test. |
| 14 | DDate | `descent_date` | GCAT: "the time when the object reentered the atmosphere or landed. If blank, the object is still in orbit." From GCAT currentcat `DDate` (a Vague Date). E.g. 2019-03-21. | **Detail:** UTC time when the object re-entered the atmosphere or landed, in Vague Date format. **Blank = the object is still in orbit.** Not the same as satcat `phase_end_date`. GCAT's documented in-orbit signal; see `flag_in_orbit` below. |
| 15 | — (composite) | `flag_in_orbit` *(existing)* | (shared block, batch 8 #5) The GCAT-only in-orbit signal (DDate blank) is `flag_gcat_in_orbit` (batch 9a). | **Corrected 2026-11-08:** the master holds only objects in the GP feed, so `flag_in_orbit` is TRUE on every row and the DDate fallback no longer applies. **v3 bug (history):** v3 used Active in A/P/S. That marked 10,516 re-entered payloads as in orbit and left out every in-orbit debris object, rocket body and component. |
| 16 | ODate | `current_orbit_epoch` | GCAT: "UTC epoch of most recent orbital data, Vague Date format." From GCAT currentcat `ODate`. Not carried into SatTrack's models. | **Detail:** UTC epoch of the most recent orbital data, in Vague Date format. Not the same as satcat `canonical_orbit_epoch`. |
| 17 | Period | `current_period_min` | Apparently the orbital period in minutes of the most recent orbit; GCAT doesn't describe this column. From GCAT currentcat `Period`. E.g. 92.9 for the ISS Zarya module. SatTrack uses GP `PERIOD` instead. | **Detail:** **UNSOURCED.** Not described on curcols.html. The values look like an orbital period in minutes (e.g. 89.768). **Staging only** (undocumented by GCAT). Filled on 36,091 rows. Orbital period comes from GP `PERIOD` instead. |
| 18 | Perigee | `current_perigee_km` | GCAT: "Conventional perigee height in km of most recent orbit. Equal to perigee radius minus equatorial radius of central body." From GCAT currentcat `Perigee`. E.g. 413 km (ISS Zarya). | **Detail:** Conventional perigee height of the most recent orbit in km: perigee radius minus the central body's equatorial radius. |
| 19 | PF | `current_perigee_flag` | Marks the most recent perigee as a guess, from GCAT currentcat `PF`: `?` or blank. Rare: about 120 objects. | **Detail:** Named on curcols.html but not defined there. In the object catalog, PF `?` = the value is a guess (cols.html). Definition taken from cols.html. |
| 20 | Apogee | `current_apogee_km` | GCAT: "Conventional apogee height in km of most recent orbit. Equal to apogee radius minus equatorial radius of central body." From GCAT currentcat `Apogee`. E.g. 423 km (ISS Zarya). | **Detail:** Conventional apogee height of the most recent orbit in km: apogee radius minus the central body's equatorial radius. |
| 21 | AF | `current_apogee_flag` | Marks the most recent apogee as a guess, from GCAT currentcat `AF`: `?` or blank. Rare: about 120 objects. | **Detail:** As PF: `?` = the value is a guess (cols.html). |
| 22 | Inc | `current_inclination_deg` | GCAT: "Inclination of most recent orbit in degrees with respect to coordinate system equator." From GCAT currentcat `Inc`. E.g. 51.63° for the ISS Zarya module; 53.16° for many Starlinks. | **Detail:** Inclination of the most recent orbit in degrees. Earth orbits are relative to the equator of date (TEME), heliocentric orbits to the J2000 ecliptic, and other bodies to their IAU equator. |
| 23 | IF | `current_inclination_flag` | Marks the most recent inclination as a guess, from GCAT currentcat `IF`: `?` or blank. Rare: about 55 objects. | **Detail:** As PF: `?` = the value is a guess (cols.html). |
| 24 | OpOrbit | `current_orbit_type_raw` | Apparently GCAT's orbit class for the most recent orbit; GCAT doesn't describe this column here. From GCAT currentcat `OpOrbit`. E.g. `LLEO/I` ("Lower LEO/Intermediate") for the ISS Zarya module. | **Detail:** Not described on curcols.html. In the object catalog it is the orbit type of the canonical orbit, with values from https://planet4589.org/space/gcat/web/intro/orbits.html. Here it presumably describes the current orbit. **Staging only.** Its meaning in currentcat (current vs canonical orbit) isn't documented. `orbit_type` uses satcat `OpOrbit` (documented). |
