# Column definitions: GCAT organisations, launch sites and launch vehicles

Part of the SatTrack column definitions; see `00_overview.md` for the rules and decisions.

## Batch 5: GCAT organisations, launch sites, launch vehicles (`orgs.tsv`, `sites.tsv`, `lv.tsv` → `stg__jsr__orgs`, `stg__jsr__sites`, `stg__jsr__lv`)

Sources:
- `orgs`: GCAT "Organizations Database", https://planet4589.org/space/gcat/web/orgs/index.html (4,144 rows on 2026-10-24; `Code` unique).
- `sites`: GCAT "Launch Origins Database", https://planet4589.org/space/gcat/web/sites/index.html (712 rows; `Site` unique).
- `lv`: GCAT "Launch Vehicle List", https://planet4589.org/space/gcat/web/lvs/lv/index.html (1,837 rows; **unique on `LV_Name` + `LV_Variant`**, with 200 duplicate names).

**v3 bug found:** `normalize_jsr_orgs` reads a column `State`, but the orgs file has `StateCode`. So `org_country_code` is **NULL for all 4,131 rows** in `dim_org` (2026-10-04 DB). It's the same class of bug as `Tx`/`EndTxDate`, and the schema-drift source test would catch it.

GCAT's own guidance on names: `ShortEName` is a "Short name in English. Useful for summary information. Can be omitted when ShortName is itself English" (sites page). So display names should prefer the English name and fall back to the host-language one; that derived rule is in batch 8.

| # | GCAT col | Proposed name | Proposed definition (from source) | SatTrack note |
|---|---|---|---|---|
| 1 | orgs.Code | `org_code` *(existing)* | GCAT: "Org Code for organization in a particular phase (time period)", 1 to 8 characters. From GCAT orgs `Code`. E.g. `SPXS` (SpaceX/Seattle), `NASA`. | **Detail:** GCAT Org Code for the organisation in a particular phase (time period): a unique string of 1–8 characters (digits, upper-case letters, dash), e.g. `NASA`, `I-ESRO`. Usually refers to a single operating location (e.g. NASA-Goddard), not the parent agency. PK. Target of every owner/manufacturer/agency code. |
| 2 | orgs.UCode | `org_ucode` | GCAT: "'unified' Org Code for organization across all time periods", linking an organisation's renamed phases. From GCAT orgs `UCode`. E.g. `FORDA` (Ford Aerospace through to Maxar); `SPXS` (SpaceX/Seattle). | **Detail:** "Unified" Org Code shared by all phases of the same organisation, e.g. FORDA for Philco WDL → Ford Aerospace → Space Systems Loral → Maxar. Usually the Code of the first phase. For current countries it's usually the Internet TLD (CN), or the single-letter code for EU countries (D, F). Lets the app group an organisation across renames. |
| 3 | orgs.StateCode | `org_state_code` *(was `org_country_code`)* | GCAT: "Org Code for the nation-state, IGO or other polity with responsibility for the organization", normally its host country. From GCAT orgs `StateCode`. E.g. `US` (SpaceX/Seattle), `CN`. | **Detail:** Org Code of the nation-state, IGO or other polity responsible for the organisation, normally the country it's located in ("host country"). Must be an org of type CY, IGO or AP. **Fixes the v3 bug** (read from `State`, which doesn't exist). Renamed to match `site_state_code`. |
| 4 | orgs.Type | `org_type` | GCAT: "Organization roles: a slash-separated set of types." From GCAT orgs `Type`; GCAT advises relying only on CY, IGO and AP. E.g. `O/PL` (payload owner and maker) for SpaceX/Seattle; `CY` (country). | **Detail:** Organisation roles, a slash-separated set (e.g. `LV/E`). Codes include CY country, CYP province, IGO intergovernmental, AP astronomical polity, E engine maker, LV launch-vehicle maker, PL payload maker, LA launch agency, O payload owner, S suborbital operator, P parent org, and LS/LP/LC/LZ for launch origins. GCAT: "somewhat patchy… I do not recommend relying on data in this column with the exception of the special values CY, IGO and AP". Use only to identify country-like orgs (CY, IGO, AP). Never filter operators by role. |
| 5 | orgs.Class | `org_class` | GCAT: "Organization class: A, B, C, or D (Nonprofit, commercial, civil or defence)." From GCAT orgs `Class`. E.g. `B` (commercial) for SpaceX/Seattle; `C` for NASA. | **Detail:** Organisation class: A academic/amateur/non-profit, B business/commercial, C civil government, D defence/military/intelligence. Usually, but not always, the same as the class of its satellites. Same codes as psatcat `ownership_class`, so it shares the label seed. |
| 6 | orgs.TStart | `org_start_date` | GCAT: "Calendar date of phase start - e.g. when the org was founded." From GCAT orgs `TStart` (a Vague Date). E.g. 2015-06-01 for SpaceX/Seattle (`2015 Jun`). | **Detail:** Start of this organisation phase (e.g. founding), in Vague Date format. Null = unknown. |
| 7 | orgs.TStop | `org_stop_date` | GCAT: "Calendar date of phase end - e.g. when the org was closed or renamed"; blank while still operating. From GCAT orgs `TStop` (a Vague Date). E.g. 1991-01-01. | **Detail:** End of this phase (e.g. closed or renamed), in Vague Date format. Null = "still in operation, or assumed to be so". `-` and `*` both mean NULL (still operating). |
| 8 | orgs.ShortName | `org_short_name` *(existing)* | GCAT: "Short name of organization (ASCII, host language)." From GCAT orgs `ShortName`. E.g. `SpaceX/Seattle`, `Blue Origin`. | **Detail:** Short ASCII name suitable for labels and tables, nominally transliterated from the host country's language. v3 coalesced it with ShortEName in staging. That moves to batch 8's display rule, so staging keeps both columns. |
| 9 | orgs.Name | `org_full_name` *(existing)* | GCAT: "Full name of organization (ASCII, host language)." From GCAT orgs `Name`. E.g. `SpaceX (Seattle)`, `Asia Broadcast Satellite Ltd.`. | **Detail:** Full name (up to 80 ASCII characters), transliterated from the host country's language. |
| 10 | orgs.Location | `org_location` *(existing)* | GCAT: "Approximate location (e.g. city)." From GCAT orgs `Location`. E.g. `Seattle:Redmond, Washington` for SpaceX/Seattle; `Beijing`, `Moskva`. | **Detail:** Approximate location (e.g. city), often as UrbanArea-Suburb, e.g. "Los Angeles-El Segundo". |
| 11 | orgs.Longitude | `org_longitude` | GCAT: "Longitude of location, deg E." From GCAT orgs `Longitude`. E.g. -122.12 for SpaceX/Seattle; 37.62 (Moscow). | **Detail:** Longitude of the location, degrees east. |
| 12 | orgs.Latitude | `org_latitude` | GCAT: "Latitude of location, deg N." From GCAT orgs `Latitude`. E.g. 47.67 for SpaceX/Seattle; 55.75 (Moscow). | **Detail:** Latitude of the location, degrees north. |
| 13 | orgs.Error | `org_location_error_deg` | GCAT: "Error in lon/lat, deg." From GCAT orgs `Error`. E.g. 0.02 degrees, the value for almost every organisation. | **Detail:** Error in longitude/latitude, in degrees. |
| 14 | orgs.Parent | `org_parent_code` | GCAT: "OrgCode of organization of which this org is a part." From GCAT orgs `Parent`. E.g. `USAF` (US Air Force), `USN`. | **Detail:** Org Code of the organisation this org is part of. FK to `org_code`, at warn level. |
| 15 | orgs.ShortEName | `org_short_name_en` | GCAT: "Short name of organization (ASCII, English)", given when the short name isn't already English. From GCAT orgs `ShortEName`. E.g. `CAS Space`, `USAF ETR`. | **Detail:** Short name in English. Filled for only 444 of 4,144 rows. |
| 16 | orgs.EName | `org_full_name_en` | GCAT: "Full name of organization (ASCII, English)." From GCAT orgs `EName`. E.g. `Thales Alenia Space`, `Arsenal Design Bureau`. | **Detail:** Full name in English. 1,398 of 4,144. |
| 17 | orgs.UName | `org_full_name_unicode` | GCAT: "Full name of organization (Unicode, host language)." From GCAT orgs `UName`. E.g. `SpaceX (Seattle)`; names in their own script where that isn't Latin. | **Detail:** Full name in Unicode, host language. |
| 18 | sites.Site | `site_code` *(existing)* | GCAT: "the Org Code for this launch site (or, for this time phase of this launch site...)." From GCAT sites `Site`. E.g. `GIK-5` (Baykonur), `CC` (Canaveral). | **Detail:** Org Code for the launch site, or for this time phase of it if the site changed name. PK. FK target of launchlog `Launch_Site`. |
| 19 | sites.Code | `site_legacy_code` | GCAT: "a blank entry (for back compatibility)." From GCAT sites `Code`; empty for every site. | **Detail:** Blank entry, kept for back compatibility. Always `-`. Kept 1:1 in staging and excluded from intermediate. |
| 20 | sites.UCode | `site_ucode` | GCAT: "the unified Org Code for all phases for this launch site." From GCAT sites `UCode`. E.g. `GIK-5` (Baykonur); `CC` covers several Canaveral phases. | **Detail:** Unified Org Code for all phases of the launch site. Not unique. v3 was right not to use it as the key. |
| 21 | sites.Type | `site_type` | GCAT: "the launch site type (LS, LC, LZ)": land launch site, launch cruise (a sea expedition) or launch zone (air/sea area). From GCAT sites `Type`. E.g. `LS` for Baykonur. | **Detail:** Site type: LS launch site (land-based), LC launch cruise (an expedition with multiple sea launch points), LZ launch zone (a compact zone of air or sea launch points). Accepted values LS, LC, LZ. |
| 22 | sites.StateCode | `site_state_code` *(was `site_country_code`)* | GCAT: "Org Code for the nation-state, IGO or other polity with responsibility for the launch site." From GCAT sites `StateCode`. E.g. `RU` for Baykonur (GIK-5); `SU`, `US`. | **Detail:** Org Code of the nation-state, IGO or other polity responsible for the site, normally the country it's located in. Must be a CY, IGO or AP org in the Organizations database. Decided 2026-10-25: exposed as `site_state` (e.g. Kourou = GUF, Baikonur = RU/SU). |
| 23 | sites.TStart | `site_start_date` | GCAT: "start and stop time of this launch site phase" (Vague Date); this is the start. From GCAT sites `TStart`. E.g. 1989 for Baykonur's GIK-5 phase. | **Detail:** Start of this site phase, in Vague Date format. `-`/`*` = unknown. |
| 24 | sites.TStop | `site_stop_date` | GCAT: "start and stop time of this launch site phase"; this is the stop, blank or `*` while in use. From GCAT sites `TStop`. Not carried into SatTrack's marts. | **Detail:** End of this site phase. `-`/`*` = still in operation, or assumed to be so. |
| 25 | sites.ShortName | `site_short_name` *(existing)* | GCAT: "a short ASCII name of the site suitable for use in labels or tables." From GCAT sites `ShortName`. E.g. `Baykonur` (GIK-5); `SHIR`, `KORO`. | **Detail:** Short ASCII name suitable for labels, nominally transliterated from the host language. |
| 26 | sites.Name | `site_name` *(existing)* | GCAT: "Transliterated full name of the launch site, in host country's language." From GCAT sites `Name`. E.g. `GIK-5, Baykonur, Kazakstan`. | **Detail:** Full name (up to 80 ASCII characters), transliterated, host language. "Where known, this is the formal name of the launch site." Its last part (e.g. "Kazakstan") seeds `site_location_country` (batch 7). |
| 27 | sites.Location | `site_location` | GCAT: "City and locality of the launch site." From GCAT sites `Location`. E.g. `Pacific Ocean`, `Minia, Atlantic Ocean` (sea launch areas). | **Detail:** City and locality of the launch site. Filled on 339 of 712. |
| 28 | sites.Longitude | `site_longitude` *(existing)* | GCAT: "geographic longitude (east-positive)... in decimal degrees." From GCAT sites `Longitude`. E.g. 63.0 for Baykonur (GIK-5). | **Detail:** Geographic longitude, east-positive, decimal degrees. For sites with several pads the position is "a bit arbitrary". |
| 29 | sites.Latitude | `site_latitude` *(existing)* | GCAT: "latitude in decimal degrees." From GCAT sites `Latitude`. E.g. 46.0 for Baykonur (GIK-5); 28.46 (Canaveral). | **Detail:** Geographic latitude, decimal degrees. |
| 30 | sites.Error | `site_location_error_deg` | GCAT: "the uncertainty of the launch site location", in degrees. From GCAT sites `Error`. E.g. 0.02 for Baykonur; 5.0 for broad ocean areas. | **Detail:** Uncertainty of the site location. GCAT gives no unit for sites; degrees by analogy with orgs. |
| 31 | sites.Parent | `site_operator_code` | GCAT: "provides an Org Code of the organization operating the launch site." From GCAT sites `Parent`. E.g. `RVSN` for Baykonur (GIK-5); `USAF`. | **Detail:** Org Code of the organisation operating the launch site, when non-empty. FK to `org_code`. |
| 32 | sites.ShortEName | `site_short_name_en` | GCAT: "Short name in English... Can be omitted when ShortName is itself English." From GCAT sites `ShortEName`. E.g. `Baykonur`, `Plesetsk`. | **Detail:** Short name in English. "Useful for summary information. Can be omitted when ShortName is itself English." |
| 33 | sites.EName | `site_full_name_en` | GCAT: "Long (full) name in English." From GCAT sites `EName`; rarely filled. E.g. `Taiyuan Space Center`. | **Detail:** Full name in English. |
| 34 | sites.Group | `site_group` | GCAT: "used to group together ocean launch sites, lunar sites, and some unknown V2 launch areas." From GCAT sites `Group`. E.g. `OCEAN`; `KB` for Baykonur. | **Detail:** Currently groups ocean launch sites, lunar sites and some unknown V2 launch areas. "Likely to be repurposed in future releases." Don't build logic on it. The schema-drift test watches it. |
| 35 | sites.UName | `site_full_name_unicode` | GCAT: "Unicode version of full name in organization's parent language." From GCAT sites `UName`. E.g. `GIK-5, Baykonur, Kazakstan`. | **Detail:** Unicode version of the full name in the parent organisation's language. |
| 36 | lv.LV_Name | `lv_name` *(existing)* | GCAT: "Name of launch vehicle." From GCAT lv `LV_Name`. E.g. `Falcon 9`, `Proton-K`. | **Detail:** Name of the launch vehicle. GCAT uses the name in use by the launch agency at the time of launch. Joins to launchlog `LV_Type`. Not unique alone (see the key note above). |
| 37 | lv.LV_Family | `lv_family` *(existing)* | GCAT: "Launch vehicle family." From GCAT lv `LV_Family`. E.g. `Falcon9` for Falcon 9; `Thor`, `Terrier`. | **Detail:** Launch vehicle family, defined by the base (first) stage. A new family starts with "a change in the tankage diameter" (families page, https://planet4589.org/space/gcat/web/lvs/family/index.html). Hidden grouping key. Not a brand: e.g. Zenit includes Antares. |
| 38 | lv.LV_Manufacturer | `lv_manufacturer_code` *(existing)* | GCAT: "Manufacturer. See the Orgs file." From GCAT lv `LV_Manufacturer`. E.g. `SPX` (SpaceX) for Falcon 9; `CALT`. | **Detail:** Org Code of the manufacturer (see the Orgs file). Composite/uncertain, split by `explode_org_codes()`. |
| 39 | lv.LV_Variant | `lv_variant` | GCAT: "Sometimes two different launch vehicles have the same name... These variants are indicated by an extra string in this field." From GCAT lv `LV_Variant`. E.g. `FT5`, `1.1` (Falcon 9 versions). | **Detail:** Distinguishes different launch vehicles with the same name, e.g. Vanguard variants with different third stages. Part of the staging PK (`lv_name`, `lv_variant`). |
| 40 | lv.LV_Alias | `lv_alias` | GCAT: "the vehicle mentioned as an alias is an alternate name for this vehicle." From GCAT lv `LV_Alias`. E.g. `ARPA Taurus` (alias of the Taurus 1110), `R-1`. | **Detail:** Alternative name for the same vehicle, e.g. Taurus 1110 has the alias "ARPA Taurus", meaning the separate ARPA Taurus entry is the same vehicle under an earlier name. Filled on 23 rows. |
| 41 | lv.LV_Min_Stage | `lv_min_stage` | GCAT: "Two numbers giving the minimum and maximum stage number"; this is the minimum, usually 1, 0 with strap-on boosters. From GCAT lv `LV_Min_Stage`. E.g. 1 for Falcon 9. | **Detail:** Minimum stage number. Usually 1, sometimes 0 for strap-on boosters, occasionally -1. `A` marks air-launch platforms. Since Aug 2026, R-7 (Soyuz) boosters are stage 0 and the core is stage 1. 2026-10-24 data has only `1` (1,402), `0` (427) and `-1` (8); no `A` yet. Text in staging, and intermediate casts to integer with `A` mapped to NULL plus `flag_air_launch_platform`. |
| 42 | lv.LV_Max_Stage | `lv_max_stage` | GCAT: "Two numbers giving the minimum and maximum stage number"; this is the maximum. From GCAT lv `LV_Max_Stage`. E.g. 2 for Falcon 9 (two stages). | **Detail:** Maximum stage number. |
| 43 | lv.Length | `lv_length_m` | GCAT: "Length (metres.) The length is approximate, and may vary when different payloads and fairings are used." From GCAT lv `Length`. E.g. 71.0 m (Falcon 9 FT3). | **Detail:** Approximate length in metres. It can vary with payload and fairing. |
| 44 | lv.LFlag | `lv_length_flag` | Marks the vehicle length as a guess, from GCAT lv `LFlag`: `?` or blank, as with the object catalog's flags. | **Detail:** **UNSOURCED.** Not described on the LV page. In the object catalogs, `?` means an estimate. **Staging only** (undocumented by GCAT). Values are only `?` or blank. |
| 45 | lv.Diameter | `lv_diameter_m` | GCAT: "Diameter (metres)." From GCAT lv `Diameter`. E.g. 3.65 m for Falcon 9. | **Detail:** Diameter in metres. |
| 46 | lv.DFlag | `lv_diameter_flag` | Marks the vehicle diameter as a guess, from GCAT lv `DFlag`: `?` or blank, as with the object catalog's flags. | **Detail:** **UNSOURCED**, as LFlag. **Staging only** (undocumented by GCAT). Values are only `?` or blank. |
| 47 | lv.Launch_Mass | `lv_launch_mass_t` | GCAT: "Launch mass, (tonnes)." From GCAT lv `Launch_Mass`. E.g. 480 t (Falcon 9 FT3). | **Detail:** Launch mass in **tonnes**. Unit differs from satellite masses (kg). |
| 48 | lv.MFlag | `lv_launch_mass_flag` | Marks the vehicle launch mass as a guess, from GCAT lv `MFlag`: `?` or blank, as with the object catalog's flags. | **Detail:** **UNSOURCED**, as LFlag. **Staging only** (undocumented by GCAT). Values are only `?` or blank. |
| 49 | lv.LEO_Capacity | `lv_leo_capacity_kg` | GCAT: "LEO payload capacity in kg, approximate; only provided for some of the orbital vehicles." From GCAT lv `LEO_Capacity`; 0 when not given. | 50 | lv.GTO_Capacity | `lv_gto_capacity_kg` | GCAT: "GTO payload capacity in kg, approximate; only provided for some of the orbital vehicles." From GCAT lv `GTO_Capacity`; 0 when not given. | 51 | lv.TO_Thrust | `lv_takeoff_thrust_kn` | GCAT: "Launch thrust, kN." From GCAT lv `TO_Thrust`. E.g. 5,886 kN (Falcon 9 FT3). | **Detail:** Launch thrust in kN. |
| 52 | lv.Class | `lv_class` | GCAT's vehicle type code. From GCAT lv `Class`. | 54 | lv.Range | `lv_range_km` | GCAT: "for IRBM/ICBMs I include an extra figure representing the range" (km). From GCAT lv `Range`; filled for about 260 vehicles. | 55 | lv.GenericName | `lv_generic_name` | The vehicle's generic name, grouping variants; GCAT doesn't describe this column. From GCAT lv `GenericName`. E.g. `Falcon 9` for every Falcon 9 variant; `Delta 2`. | **Detail:** **UNSOURCED definition** (the column isn't described on the LV page).
