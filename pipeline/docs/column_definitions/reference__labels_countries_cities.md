# Column definitions: Reference data: GCAT code labels, pycountry, GeoNames

Part of the SatTrack column definitions; see `00_overview.md` for the rules and decisions.

## Batch 7: reference data (GCAT code tables parsed from pcols.html → `stg__jsr__gcat_code_labels`; pycountry → `stg__pycountry__iso_countries`; GeoNames → `stg__geonames__cities`, `stg__geonames__countries`)

Source: pycountry, https://pypi.org/project/pycountry/ (ISO 3166-1 and ISO 3166-3).

Sources by table:
- `gcat_code_labels`: GCAT "Payload Catalog Column Descriptions", https://planet4589.org/space/gcat/web/cat/pcols.html. Its Category and Class code tables are parsed at ingestion by `ingestion/sattrack_ingest/gcat_docs.py` into `raw_jsr.gcat_code_labels` (refreshed on the GCAT schedule; ingestion fails closed if the page layout changes or two short labels collide).
- `pycountry`: pycountry, https://pypi.org/project/pycountry/. It "provides the ISO databases for the standards… 3166-1 … 3166-3 (Deleted countries)… The package includes a copy from Debian's pkg-isocodes"; its `historic_countries` "contains former countries that have been removed from the standard". Pinned in requirements and landed by `ingest_pycountry` into `raw_pycountry.iso_countries`.
- `geonames`: GeoNames cities15000 and the GeoNames country list via the pinned `geonamescache` package, landed by `ingest_geonames` into `raw_geonames.cities` and `raw_geonames.countries`; field meanings per the GeoNames export readme, https://download.geonames.org/export/dump/readme.txt. Cities give the launch-site location country; country names are the second name list of the owner country (batch 8 #11).
- `launch_vehicle_manufacturer_map`, `country_alias_map`, `site_location_country`: retired SatTrack seed files with no publisher (dropped or replaced 2026-10-25, plan §15.1); no current model produces their columns.

**Unattended operation (2026-10-25, plan §15):** there are no manual or ad hoc files left. The rows below that came from manual seeds are marked retired; their doc blocks are kept so the names stay reserved.

**v3 finding:** `MANUAL_ALIAS_MAP` maps `CIS` to no country, so all 5,425 GP objects Space-Track codes as `CIS` (Soviet and Russian) have **no country in v3**. The 2026-10-25 decision (split USSR/Russia using GCAT State) fixes this.

Reviewer note: **GCAT's orgs table is also a country registry.** Orgs of type CY, IGO or AP carry GCAT's country codes, including historic ones (SU, CSSR) and IGOs (ESA), with English names (`ShortEName`/`EName`). Since GCAT `State` and `StateCode` values must be such orgs, they can be named from GCAT itself, and pycountry is only needed for Space-Track codes and ISO alignment. It's a possible simplification of D3, raised for discussion rather than decided.
